# GenAI Text Translator

## 📌 About the Project
The GenAI Text Translator is an AI-powered application that translates text from one language to another. It uses pre-trained language translation models from Hugging Face to generate translated text quickly and efficiently.

## 🎯 Objectives
- Translate text between different languages.
- Support English-to-Tamil translation.
- Explore Generative AI and Natural Language Processing (NLP).
- Build a simple translation application using Python.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **AI Platform:** Hugging Face
- **Model:** Helsinki-NLP/opus-mt-en-ta
- **Libraries:** Transformers, PyTorch
- **Interface:** Command Line / Streamlit (optional)

## ✨ Features
- English-to-Tamil text translation.
- Pre-trained translation model.
- Simple user
